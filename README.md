# Expense Tracker

A simple expense tracker to record daily expenses and keep track of monthly spending.

## Features
- Add expenses with name, amount, category and date
- Calculate total spending
- Calculate current-month spending
- Delete expenses
- Saves data in the browser using localStorage
- Responsive design for mobile and desktop

## How to run
Open `index.html` in a web browser.

## Technologies
- HTML
- CSS
- JavaScript
- Browser LocalStorage

## Project purpose
This project was created as a simple practice project to learn frontend development and JavaScript.
